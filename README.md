# Animal Island — Obsidian Theme

A cozy animal-forest style theme for [Obsidian](https://obsidian.md).
Think warm parchment, earth-brown text, a mint-teal accent, pill-shaped controls and
chunky "game button" primary actions.

![Animal Island theme screenshot](screenshots/screenshot.png)

![Animal Island theme in a full Obsidian window](screenshots/screenshot-full.png)

<img src="screenshots/screenshot-mobile.jpeg" alt="Animal Island theme on mobile" width="300">

1. Open Obsidian → Settings → Appearance → Themes, and select **Animal Island**.
2. Both dark/light modes are supported:
   - Light = **Island Day** (parchment + mint green, original color scheme)
   - Dark = **Island Night** (warm dark brown parchment, same color palette)
